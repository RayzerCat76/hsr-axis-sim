5. Duration semantics
Implement these duration types for this task:

A. `target_normal_turns`
- Decrements only when the buff/debuff holder completes a normal turn.
- Does NOT decrement during extra turns.
- Does NOT decrement when an action has `DoesNotEndTurn` and the turn remains open.
- Expires when remaining_turns reaches 0 after the tick.

B. `current_turn`
- Exists until the active turn context actually ends.
- Must survive actions with `DoesNotEndTurn`.
- Expires when the active turn finally ends.
- This is for temporary effects like "during this turn".

Do not add more duration types unless needed for tests.

6. TurnContext / Timeline integration
- TurnContext should clearly expose whether the current turn is an extra turn.
- Timeline.next_turn should set that correctly.
- Timeline.end_turn should be responsible for the appropriate duration ticks/expiration.
- Extra turns must not tick `target_normal_turns` durations.
- Normal turns must tick the acting unit's `target_normal_turns` buffs/debuffs at end of turn.
