Unit model requirements:

Extend `Unit` while preserving backward compatibility with existing construction:

```python
Unit("id", "Name", "ally", 100)
```

Add fields with safe defaults:

```python
element: str | None = None
weaknesses: list[str] = []
max_toughness: float = 0
current_toughness: float | None = None
is_broken: bool = False
```

Rules:
- If `current_toughness is None`, set it to `max_toughness`.
- If `max_toughness <= 0`, the unit should be considered to have no toughness bar.
- Toughness should never go below 0.
- Existing tests must not need edits except where explicitly extending coverage.

Effect requirements:

Add a generic effect such as:

```python
@dataclass
class DealToughnessDamage(UnitEffect):
    amount: float
    element: str | None = None
    ignore_weakness: bool = False
    break_delay_percent: float = 0.25
```

Suggested behavior:

1. Resolve target units using the existing `UnitEffect` target resolution system.
2. If target has `max_toughness <= 0`, do nothing.
3. If `ignore_weakness` is false and `element` is not in target.weaknesses, do not reduce toughness.
4. If target is already broken, do not reduce toughness further.
5. Reduce `current_toughness` by `amount`, clamped to 0.
6. If toughness crosses from >0 to 0, trigger weakness break:
   - set `target.is_broken = True`
   - keep `current_toughness = 0`
   - apply break action delay using the existing AV semantics:
     `target.current_av += target.base_av * break_delay_percent`
   - append a readable log entry such as `break:<target_id>`

Break-state recovery MVP:

Use a simple deterministic rule for this task:

- Broken state persists until the broken unit completes its next **normal** turn.
- At the end of that normal turn:
  - `is_broken = False`
  - `current_toughness = max_toughness`

Implementation hint:
- This likely belongs in `Timeline.end_turn` or a helper called from there.
- Extra turns should not recover toughness unless the broken unit is taking a normal turn.
- Do not add full HSR break damage or element-specific break status yet.
