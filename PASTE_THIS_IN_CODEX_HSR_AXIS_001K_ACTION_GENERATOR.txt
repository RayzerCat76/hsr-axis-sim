Current task:
Implement Action Generator / Resource-Gated Skill Legality MVP.

Goal:
Create a deterministic module that can enumerate legal actions for a given actor in the current BattleState using loaded SkillSpec data.

This is NOT AI search yet. This task only generates legal one-step choices. Future search will call this generator repeatedly.

At minimum:


Resource rules for this MVP:

- If `skill.sp_delta` is negative, require `state.skill_points >= -skill.sp_delta`.
- If `skill.sp_delta` is zero or positive, do not make the skill illegal. Skill point gain is capped during execution by existing effects.
- If `skill.energy_delta` is negative, require actor energy `>= -skill.energy_delta`.
- If `skill.energy_delta` is zero or positive, do not make the skill illegal.
- Unknown actor should fail clearly.
- Dead actor should not generate actions.
- This task should not try to infer affordability from every effect. Use SkillSpec metadata for MVP gating. Effects will still validate during execution.

4. Implement legal action generation.

Required function:

```python
def legal_action_choices_for_actor(state, actor_id, skills) -> list[ActionChoice]:
    ...
```

Where `skills` may be either:

```python
list[SkillSpec]
```

or:

```python
dict[str, SkillSpec]
```

Choose one API and document it in tests and README. If supporting both is easy and clean, that is acceptable.

Generation rules:

- Actor must exist.
- Actor must be alive.
- Iterate skills in deterministic order. If `skills` is a dict, preserve insertion order.
- Skip unaffordable skills.
- For each affordable skill, call `legal_target_groups(state, actor_id, skill.target_type)`.
- For each target group, build an Action using:

```python
action_from_skill(
    skill,
    actor_id=actor_id,
    target_ids=target_group,
    state=state,
    validate_targets=True,
)
```

- Return `ActionChoice` entries in stable order:
  1. skill order
  2. target group order from `legal_target_groups`

5. Optional useful function:

6. Add tests.

Required tests:

- It generates one choice per legal alive enemy target for `single_enemy` skills.
- It excludes dead targets.
- It excludes a skill when SP is insufficient.
- It includes the same skill when SP is sufficient.
- It excludes an energy-consuming skill when energy is insufficient.
- It includes an energy-consuming skill when energy is sufficient.

- It supports an AoE/no-selected-target skill such as `all_enemies` by generating one choice with `target_ids == []`.
- It returns `[]` for a dead actor.
- It fails clearly for an unknown actor.
