Goal:
Add a deterministic MVP for HSR-style ultimate / interrupt decision windows.

The simulator must be able to answer:
1. Which characters can legally use an ultimate at an interrupt window?
2. What target choices are legal for those ultimates?
3. Can an interrupt ultimate be executed without advancing global AV or resetting the actor's normal timeline position?
4. Can replay validation include an interrupt step between normal turns?

Scope:
This task is only an MVP for off-turn ultimate timing. It is not AI search.

Required behavior:

1. Add an interrupt/ultimate window module

Create a new module such as:

```text
hsr_axis_sim/sim/ultimate_windows.py
```

or another clear name.

Implement:

```python
@dataclass
class DecisionWindow:
    window_type: str
    active_actor_id: str | None = None
    source: str | None = None
```

Recommended window types for MVP:

```text
manual_interrupt
before_actor_action
after_actor_action
before_next_turn
```

The window type is mostly metadata in this task. Do not build search yet.

2. Enumerate legal ultimate choices

Implement a deterministic function similar to:

```python
def legal_ultimate_choices(
    state: BattleState,
    skill_lookup: dict[str, dict[str, SkillSpec]],
    window: DecisionWindow | None = None,
) -> list[ActionChoice]:
    ...
```

Rules:
- Iterate units in `state.units` order.
- Skip dead units.
- Only consider skills with `skill.skill_type == "ultimate"`.
- Use existing affordability checks from 001K.
- Use existing target legality from 001J.
- Use existing `action_from_skill(..., validate_targets=True)`.
- Preserve deterministic order: unit order, skill order, target group order.
- Do not mutate battle state.

3. Add interrupt execution helper

Implement a helper similar to:

```python
def execute_interrupt_action(
    state: BattleState,
    action: Action,
    forced_rng: dict | None = None,
) -> TurnContext:
    ...
```

Rules:
- It must not call `Timeline.next_turn`.
- It must not advance `state.global_av`.
- It must not subtract AV from units.
- It must not reset the actor's `current_av` by adding base AV.
- It must not tick target-normal-turn buff/debuff durations.
- It must not expire current-turn statuses.
- It should execute the action effects and trigger normal action events.
- It should use a `TurnContext` that clearly marks this as an interrupt if you add such a field.
- Interrupt actions should normally have `ends_turn=False`. If an interrupt action has `ends_turn=True`, raise a clear error rather than accidentally ending a normal turn.

You may extend `TurnContext` with:

```python
is_interrupt: bool = False
```

Do not treat interrupt actions as extra turns. They are not normal turns and not extra turns.

4. Extend Replay Validator for interrupt steps

Replay validation currently selects `Timeline.next_turn(state)` for each step. Extend it so a step can be marked as an interrupt step.

Example schema:

```json
{
  "step": 2,
  "step_type": "interrupt",
  "actor_id": "seele_like",
  "skill_id": "ultimate",
  "target_ids": ["enemy_1"],
  "forced_rng": {"crit": true},
  "expect": {
    "global_av": 74.6268656716418,
    "units": {
      "seele_like": {"energy": 0},
      "enemy_1": {"hp": 5000}
    }
  }
}
```

Rules:
- For normal steps, preserve old behavior.
- For interrupt steps, do not call `Timeline.next_turn`.
- The replay step must provide `actor_id` or `expected_actor`.
- Use the loaded skill if `skill_id` is provided.
- Validate that the skill is an ultimate unless the step explicitly opts out for a test-only action.
- Use `execute_interrupt_action`.
- Existing replay files must keep passing unchanged.
