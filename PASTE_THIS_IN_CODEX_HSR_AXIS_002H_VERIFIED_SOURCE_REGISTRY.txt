Goal
====

Create a deterministic, non-executable, field-level source registry for the exact real-character facts needed by the first trace.

The registry must answer:

1. Which source supports each claimed fact?
2. What game version, language, and retrieval date apply?
3. Is the source official, structured-database-derived, or manually verified?
4. Is a fact verified, conflicting, incomplete, or unresolved?
5. Which first-trace action/gap does the fact relate to?
6. Which facts are still missing before any simulator binding can begin?

This task is provenance and research only. Do not implement character kits or make the trace executable.

Source policy
=============

Prioritize sources in this order:

1. Official in-game text or official HoYoverse/HoYoLAB character information where available.
2. Reliable structured game-data sources that expose versioned numerical fields.
3. The accepted manual-video evidence already stored in this repository.
4. Community mechanics references only for facts not available above, clearly labeled as community-derived.

Rules:

- Every external source must have a stable URL or source identifier.
- Record source title, publisher/domain, source type, language, game version if known, and retrieval date.
- Prefer current/live version facts relevant to the recorded 3.4 trace.
- If a source is beta, leaked, stale, mirrored, or version-ambiguous, mark it and do not treat it as verified live data.
- Do not store long verbatim skill descriptions. Use short paraphrases and numeric/structural facts only.
- Do not silently resolve conflicting sources. Record the conflict and leave the affected fact unresolved.
- Do not infer a fact from animation alone when it is not present in accepted evidence or a verified source.
