Chosen action for this task
===========================

Implement only the source-reviewed, currently supported shell of **Pela Skill**.

Use only these accepted atomic fields:

- actor ID: `pela`
- action category: `skill`
- target scope: `single_enemy`
- skill-point delta: `-1`
- energy generation: `30`
- dispel count: `1`

Explicitly unresolved and prohibited in 002J:

- damage multiplier or final damage;
- trace level and build assumptions;
- observed real-video target;
- normalized toughness value;
- any source-native toughness conversion;
- debuff application not directly part of the accepted Skill facts;
- eidolon, trace, light-cone, relic, or team interactions.

Goal
====

Create the smallest reviewed executable binding that proves atomic facts can map safely to existing generic engine primitives without pretending to implement Pela's complete in-game Skill.

The implementation must be named and reported as a **partial binding shell**, not a complete character skill.

Mandatory pre-flight
====================

1. Inspect existing generic primitives for:

- single-enemy target validation;
- skill-point consumption;
- actor energy gain;
- removable buff/dispel behavior;
- normal-turn action execution.

2. Do not modify a generic primitive unless an independently reproducible engine defect is found. If a primitive lacks required semantics, add the smallest generic extension with focused tests and document it.

3. Confirm the 002I atomic-fact artifact is unchanged.

Required implementation
=======================

1. Add a reviewed binding model or module under a clearly separate real-binding namespace, for example:

`hsr_axis_sim/real_bindings/pela_skill_v0_1.py`

or an equivalent data-driven path.

2. The binding must explicitly contain:

- binding ID and version;
- source atomic fact IDs used;
- unresolved atomic fact IDs/fields;
- `binding_scope: partial_resource_target_dispel_shell`;
- `complete_game_skill: false`;
- target type `single_enemy`;
- SP cost 1;
- actor energy gain 30;
- dispel count 1;
- no damage effect;
- no toughness effect.

3. Add a strict guard preventing this partial binding from being registered or labeled as a complete Pela kit.

4. Add a synthetic deterministic fixture. Do not use the real video trace as an executable fixture yet.

Synthetic fixture requirements:

- Pela-like actor with sufficient SP context;
- one alive enemy target carrying at least two removable buffs or positive statuses;
- execute the partial binding once;
- verify exactly one removable status is removed according to a deterministic ordering rule;
- verify SP decreases by 1;
- verify Pela energy increases by 30;
- verify no damage occurs;
- verify no toughness changes;
- verify normal timeline/turn behavior remains correct.

5. Define and test deterministic dispel ordering. Reuse an existing ordering rule if one already exists. Do not invent random removal.

6. Add a binding audit report in Markdown and JSON containing:

- atomic fields bound;
- atomic fields deliberately not bound;
- generic primitives used;
- any generic extension added;
- synthetic fixture result;
- why the real trace remains non-executable;
- `complete_game_skill: false` warning.
