Execution contract
==================

The binding must execute only through the existing reviewed registry public path.

Expected behavior:

1. Validate exactly one legal ally target using existing target legality.
2. Build an `Action` for actor `tingyun` with `ends_turn=False`.
3. Consume 130 Energy from Tingyun using the existing generic energy primitive.
4. Restore 50 Energy to the selected ally using the existing generic energy primitive.
5. Execute with the existing Ultimate interrupt mechanism.
6. Return a `TurnContext` with:
   - `is_interrupt=True`;
   - `should_end_turn=False`.
7. Do not advance global AV.
8. Do not change any unit's normal timeline AV.
9. Do not produce `normal_turn_end`.
10. Do not change SP.
11. Do not add a buff.
12. Do not deal damage or toughness damage.

Effect ordering must be fail-safe:

- consume Tingyun's Energy before restoring target Energy;
- if Tingyun has insufficient Energy, the action must fail before target Energy changes.

Do not use the observed real-video target. The synthetic fixture target is test-only and must not be presented as trace evidence.
