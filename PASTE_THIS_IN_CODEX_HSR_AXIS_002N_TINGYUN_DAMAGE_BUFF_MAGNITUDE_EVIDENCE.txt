Goal
====

Capture and normalize a version-qualified, source-backed level-scaling table for the DMG-increase component of Tingyun's Ultimate.

This is an evidence-only task. It must not implement the buff in the simulator.

Scope
=====

- executable simulator binding.

Source requirements
===================

1. Prefer release/live structured game data with an exact field locator or stable structured path.
2. Seek at least one independent corroborating source for the level table.
3. Record for every accepted source:
   - source ID;
   - title;
   - locator;
   - source type;
   - language;
   - game version or snapshot qualification;
   - retrieval date;
   - exact field/page locator;
   - whether the source supports the exact field or only context.
4. Preserve the source's raw level numbering and values before normalization.
5. Do not infer missing levels from memory, interpolation, a single displayed level, guide prose, or the recorded video.
6. Do not claim that a current page is byte-identical to version 3.4 unless the source proves it.
7. If browsing or an exact table is unavailable, stop safely and produce a blocked evidence-intake result. Do not invent values.

Normalization contract
======================

If a valid table is captured, create an evidence-only normalized representation that clearly distinguishes:

- raw source level index;
- normalized trace level, only where mapping is explicitly supported;
- DMG increase value;
- unit (`percent`);
- version applicability;
- provenance for each normalized row or table block.

Do not assume the player-accessible maximum trace level. Preserve extra source rows separately if the structured source exposes internal levels beyond normal gameplay.
