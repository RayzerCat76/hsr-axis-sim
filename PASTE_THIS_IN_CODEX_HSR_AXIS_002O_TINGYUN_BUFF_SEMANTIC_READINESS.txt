Goal
====

Create a deterministic, non-executable readiness review that answers two separate questions:

1. Is a generic source-reviewed Tingyun Ultimate DMG-buff binding ready to be implemented when the caller supplies a legal ally target and an explicit trace level?
2. Is the accepted real-video trace ready to bind to a concrete target and magnitude?

The report must not conflate those two readiness axes.

Evidence questions to investigate
=================================

A. Effect ordering
- Does the game apply the target Energy restoration before or after the DMG buff?
- Prefer a pinned release-data behavior/effect-sequence locator.
- A prose description that merely lists both effects does not prove order.
- If no exact source exists, keep order unresolved.

B. Same-current-turn duration edge
- If Tingyun casts the Ultimate during the selected ally's already-active normal turn, does that turn's end consume the first of the two duration counts?
- Prefer exact release behavior data or a controlled interaction record with a reproducible protocol.
- Do not infer this from the existing engine behavior.
- If no exact evidence exists, keep the edge unresolved.

C. Magnitude evidence integration
- Treat the 002N captured table as source-backed evidence.
- Validate its input path/digest or deterministic content before consuming it.
- Do not copy a single level into executable code.
- Do not infer the accepted video's Tingyun trace level.
