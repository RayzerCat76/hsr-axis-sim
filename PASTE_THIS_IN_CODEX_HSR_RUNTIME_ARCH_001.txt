Objective
=========

Create a clean, non-invasive, importable contract skeleton for the future
universal HSR Runtime.

This task is interface-only.

It must provide:

1. stable string enums for generic runtime concepts;
2. immutable Action / Attack / Hit context dataclasses;
3. a generic runtime event envelope;
4. evidence and semantic-binding gates;
5. deterministic canonical serialization;
6. trace-record structures that separate raw/internal values from displayed
   values;
7. a checked-in unresolved-semantics registry generated from the v1.0 research
   baseline;
8. documentation describing the migration boundary.

Do not connect the new contracts to the existing simulator execution path.
Do not modify production combat behavior.

Validation requirements:

### HitContext minimum fields


Validation requirements:

- `hit_index >= 0`.
- IDs are non-empty.
- Application request IDs are unique and deterministic.

The dataclasses are contracts only. They must not import or call:

- `hsr_axis_sim.sim.Action`
- `BattleState`
- `Timeline`
- existing `Effect` classes
- search or regression code

4. Evidence and semantic gates
------------------------------

Create:

```text
SemanticContract
UnresolvedMechanicError
```

`SemanticContract` minimum fields:

```python
mechanic_id: str
evidence_status: EvidenceStatus
binding_status: BindingStatus
selected_policy: str | None
source_refs: tuple[str, ...]
notes: str | None
```

Validation rules:

- `CONFIRMED + BOUND` requires at least one source reference.
- `PARTIAL` may only be `INTERFACE_ONLY` or `UNRESOLVED`.
- `UNKNOWN` must be `UNRESOLVED`.
- `BOUND` is forbidden for `PARTIAL` or `UNKNOWN`.
- `UNRESOLVED` must not invent a selected policy.
- no empty source-reference strings;
- source references are unique and deterministically ordered.

Add an explicit method such as:

```python
require_bound()
```

It must raise controlled `UnresolvedMechanicError` unless the contract is
legally `BOUND`.

No silent fallback is allowed.

6. Deterministic serialization
------------------------------

Create canonical serialization helpers.

Requirements:

- stable dictionary field order or canonical `sort_keys=True` JSON;
- compact deterministic JSON option;
- pretty deterministic JSON option;
- tuples/enums/dataclasses serialize deterministically;
- reject unsupported opaque Python objects with controlled `TypeError`;
- never silently convert an unknown object using `repr()`.

7. Trace contracts
------------------

Create frozen trace structures, at minimum:

```text
TraceNumericValue
RuntimeTraceRecord
```

`TraceNumericValue` must separate:

```python
raw_value: str
displayed_value: str | None
quantization_policy: QuantizationPolicy
```

Using a string for `raw_value` is intentional: this contract must be able to
preserve Decimal/rational text without forcing binary-float rounding.

`RuntimeTraceRecord` must include:

```python
sequence: int
event: RuntimeEvent
action_context: ActionContext | None
attack_context: AttackContext | None
hit_context: HitContext | None
numeric_values: Mapping[str, TraceNumericValue]
notes: tuple[str, ...]
```

Validation:

- `sequence >= 0`;
- nested context IDs must agree when multiple contexts are present;
- numeric-value keys and notes are deterministic;
- canonical JSON round-trip is byte-stable.

Do not add a trace writer to the existing simulator in this task.
