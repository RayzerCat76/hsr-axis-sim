Objective
=========

Create a standard-library-only, manually invoked, one-way adapter that converts
existing legacy `hsr_axis_sim.sim.events.Event` observations into immutable
`hsr_axis_sim.runtime_contracts.RuntimeEvent` envelopes.

This task creates an observation bridge only.

It must not:

- hook or modify `BattleState.emit_event`;
- dispatch RuntimeEvents back into the simulator;
- alter triggers;
- reconstruct ActionContext, AttackContext, or HitContext;
- infer action family, priority, turn kind, attack ID, or hit ID;
- change any combat, replay, search, data, timeline, LIFO, formula, or lifecycle
  behavior.

1. Explicit adapter policies
----------------------------

Define stable string enums:

```text
UnknownLegacyEventPolicy:
  PRESERVE_AS_CONTENT_DEFINED
  REJECT

AmbiguousLegacyEventPolicy:
  PRESERVE_AS_CONTENT_DEFINED
  REJECT
```

Neither policy may have a default.

Create a frozen configuration dataclass:

```python
LegacyEventAdapterConfig:
    stream_id: str
    unknown_event_policy: UnknownLegacyEventPolicy
    ambiguous_event_policy: AmbiguousLegacyEventPolicy
```

Requirements:

- all fields are mandatory;
- `stream_id` is a non-empty deterministic identifier;
- no environment time, UUID, random value, object identity, or process ID may
  be used;
- config mutation is rejected.

2. Mapping contracts
--------------------

Create a frozen `LegacyEventMapping` contract with at least:

```python
legacy_event_type: str
runtime_event_type: RuntimeEventType
semantic_contract: SemanticContract
normalized_field_map: Mapping[str, str]
notes: str | None
```

Create an immutable mapping registry containing exactly these seven known
legacy event types:

```text
action_started
action_finished
turn_started
turn_ended
damage_dealt
weakness_break
unit_defeated
```

Required normalized mappings:

```text
action_started  -> ACTION_START
action_finished -> ACTION_END
turn_started    -> TURN_START
turn_ended      -> TURN_END
damage_dealt    -> DAMAGE_RESOLVED
weakness_break  -> WEAKNESS_BROKEN
unit_defeated   -> CONTENT_DEFINED
```

Bound field extraction:

```text
action_started:
  actor_id <- actor_id
  action_id <- action_id

action_finished:
  actor_id <- actor_id
  action_id <- action_id

turn_started / turn_ended:
  actor_id <- actor_id

damage_dealt / weakness_break:
  source_id <- source_id
  target_id <- target_id

unit_defeated:
  target_id <- target_id
```

Do not:

- infer `attack_id`;
- infer `hit_id`;
- infer `source_id` from `killer_id`;
- infer lifecycle type from `unit_defeated`;
- infer turn kind or priority from `is_extra_turn`.

Semantic contracts:

### Six bound mappings

For:

```text
action_started
action_finished
turn_started
turn_ended
damage_dealt
weakness_break
```

use:

```text
evidence_status = CONFIRMED
binding_status = BOUND
selected_policy = exact RuntimeEventType string
source_refs = fixed repository source locator(s)
```

### Ambiguous lifecycle mapping

For:

```text
unit_defeated
```

use:

```text
mechanic_id = LEGACY_EVENT.UNIT_DEFEATED_LIFECYCLE
evidence_status = UNKNOWN
binding_status = UNRESOLVED
selected_policy = null
runtime_event_type = CONTENT_DEFINED
```

The adapter may preserve this event only when the caller explicitly chooses:

```text
AmbiguousLegacyEventPolicy.PRESERVE_AS_CONTENT_DEFINED
```

Otherwise raise a controlled error.

3. Controlled errors
--------------------

Create controlled exception types:

```text
LegacyEventAdapterError
UnmappedLegacyEventError
AmbiguousLegacyEventError
LegacyEventSchemaError
```

Requirements:

- unknown legacy event with `REJECT` raises `UnmappedLegacyEventError`;
- ambiguous `unit_defeated` with `REJECT` raises
  `AmbiguousLegacyEventError`;
- malformed legacy type, data mapping, or normalized ID field raises
  `LegacyEventSchemaError`;
- never silently fall back;
- never stringify unsupported payload objects with `repr()`.

4. Single-event adaptation
--------------------------

Provide a pure function or stateless adapter method equivalent to:

```python
adapt_legacy_event(
    event: hsr_axis_sim.sim.events.Event,
    *,
    sequence: int,
    config: LegacyEventAdapterConfig,
) -> RuntimeEvent
```

Requirements:

- `sequence >= 0`;
- deterministic event ID:

```text
legacy:{stream_id}:{sequence}
```

- no zero-padding or locale-dependent formatting;
- bound known events use their exact mapped RuntimeEventType;
- ambiguous or explicitly preserved unknown events use
  `RuntimeEventType.CONTENT_DEFINED`;
- `attack_id = None`;
- `hit_id = None`;
- only explicitly listed normalized ID fields are extracted;
- original event data is preserved under a nested `legacy_data` payload;
- adapter metadata is preserved under a nested `adapter` payload.

Required adapter payload metadata:

```text
adapter_name = legacy_mvp_event_adapter
adapter_version = 1.0
legacy_event_type
mapping_status = BOUND | AMBIGUOUS | UNMAPPED_PRESERVED
mechanic_id
binding_status
semantic_gap_ids
```

For unknown preserved events:

```text
mechanic_id = LEGACY_EVENT.UNMAPPED_TYPE
binding_status = UNRESOLVED
semantic_gap_ids = ["LEGACY_EVENT.UNMAPPED_TYPE"]
```

For `unit_defeated`:

```text
semantic_gap_ids = ["LEGACY_EVENT.UNIT_DEFEATED_LIFECYCLE"]
```

The `legacy_data` payload must be a defensive immutable snapshot. Mutating the
original legacy event or its nested data after adaptation must not alter the
RuntimeEvent.

5. Event-stream adaptation
--------------------------

Provide a function equivalent to:

```python
adapt_legacy_event_stream(
    events: Iterable[Event],
    *,
    start_sequence: int,
    config: LegacyEventAdapterConfig,
) -> tuple[RuntimeEvent, ...]
```

Requirements:

- input order is preserved;
- sequences are contiguous from `start_sequence`;
- event IDs are deterministic;
- iterable is consumed exactly once;
- returns a tuple;
- does not mutate or clear the input list;
- does not read or mutate BattleState;
- the caller may manually pass `state.pending_events`, but the adapter must not
  import or call `BattleState.emit_event`.

6. Raw-payload preservation
---------------------------

Required RuntimeEvent payload structure:

```json
{
  "adapter": {
    "adapter_name": "legacy_mvp_event_adapter",
    "adapter_version": "1.0",
    "binding_status": "...",
    "legacy_event_type": "...",
    "mapping_status": "...",
    "mechanic_id": "...",
    "semantic_gap_ids": []
  },
  "legacy_data": {}
}
```

Requirements:

- preserve all legacy keys and values;
- preserve optional `is_break_damage`;
- preserve nested `formula_parts`;
- no field deletion;
- no numeric rounding;
- no conversion into `TraceNumericValue`;
- unsupported opaque or non-finite values fail through controlled validation;
- canonical serialization through existing runtime-contract helpers is
  deterministic.
