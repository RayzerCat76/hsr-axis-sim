Objective
=========

Create a standard-library-only, sidecar trace export layer that accepts an
explicit iterable of immutable `RuntimeEvent` objects and produces:

1. one `RuntimeTraceRecord` per event;
2. an immutable `RuntimeTraceDocument`;
3. deterministic compact or pretty UTF-8 JSON bytes;
4. a SHA-256 digest over the exact exported bytes;
5. an optional, explicitly requested file write.

The export layer must be read-only with respect to the simulator.

It must not:

- import or read `BattleState`;
- read or clear `pending_events`;
- hook `emit_event`;
- observe battles automatically;
- mutate RuntimeEvents;
- reconstruct Action/Attack/Hit contexts;
- extract or quantize numeric values;
- load, parse, validate, or compare trace files;
- alter any production behavior.

1. Explicit export policies
---------------------------

Define stable string enums:

```text
TraceSequencePolicy:
  CONTIGUOUS
  STRICTLY_INCREASING

EmptyTracePolicy:
  ALLOW
  REJECT
```

Neither enum may have a default selection.

Create a frozen configuration dataclass:

```python
TraceExportConfig:
    trace_id: str
    sequence_policy: TraceSequencePolicy
    empty_trace_policy: EmptyTracePolicy
    metadata: Mapping[str, JSON-compatible value]
```

Requirements:

- all fields are mandatory;
- `trace_id` is a non-empty string;
- policy values must be the exact enum types;
- metadata is defensively copied/frozen;
- unsupported opaque objects and non-finite floats are rejected;
- no timestamp, UUID, process ID, object identity, environment value, or random
  value is generated;
- config mutation is rejected.

RuntimeTraceExportError

Requirements:

3. RuntimeTraceDocument
-----------------------

Create a frozen dataclass:

```python
RuntimeTraceDocument:
    schema_name: str
    schema_version: str
    trace_id: str
    sequence_policy: TraceSequencePolicy
    record_count: int
    first_sequence: int | None
    last_sequence: int | None
    event_type_counts: Mapping[str, int]
    semantic_gap_ids: tuple[str, ...]
    records: tuple[RuntimeTraceRecord, ...]
    metadata: Mapping[str, JSON-compatible value]
```

Required fixed values:

```text
schema_name = hsr_runtime_trace
schema_version = 1.0
```

Prefer `init=False` fixed dataclass fields or an equivalent design that prevents
callers from selecting another schema name/version.

Validation:

- `trace_id` non-empty;
- `record_count == len(records)`;
- empty document has `first_sequence = null` and `last_sequence = null`;
- non-empty document boundaries equal the first and last record sequences;
- event-type counts exactly match records;
- semantic gaps are unique and deterministically sorted;
- records are a tuple and immutable;
- metadata and count mappings are defensively frozen;
- document mutation is rejected.

4. Event-to-record projection
-----------------------------

Provide a pure function equivalent to:

```python
runtime_event_to_trace_record(event: RuntimeEvent) -> RuntimeTraceRecord
```

It must create exactly:

```text
record.sequence = event.sequence
record.event = event
record.action_context = None
record.attack_context = None
record.hit_context = None
record.numeric_values = {}
record.notes = ()
```

Requirements:

- input must be `RuntimeEvent`;
- no new event is created;
- the original immutable event object is retained in the record;
- do not infer ActionContext, AttackContext, HitContext, attack ID, hit ID,
  lifecycle, or numeric values;
- do not inspect legacy `amount` or `formula_parts` for numeric conversion.

5. Document building
--------------------

Provide a function equivalent to:

```python
build_runtime_trace_document(
    events: Iterable[RuntimeEvent],
    *,
    config: TraceExportConfig,
) -> RuntimeTraceDocument
```

Requirements:

- validate config before consuming the iterable;
- consume the iterable exactly once;
- preserve input order;
- do not mutate the input collection;
- reject any non-RuntimeEvent item;
- preserve original event sequences; never renumber;
- reject duplicate `event_id` values.

Sequence policies:

### CONTIGUOUS

For each adjacent pair:

```text
next.sequence == previous.sequence + 1
```

### STRICTLY_INCREASING

For each adjacent pair:

```text
next.sequence > previous.sequence
```

Both policies reject repeated or decreasing sequence numbers.

Empty policies:

```text
ALLOW:
  produce an empty document

REJECT:
  raise EmptyRuntimeTraceError
```

No policy may be selected implicitly.

Event type counts:

```text
key = RuntimeEventType.value
value = exact number of records
```

Keys must be deterministically sorted in canonical output.

6. Semantic-gap aggregation
---------------------------

For each event:

- if `event.payload` has no `adapter` key, contribute no gap;
- if it has an `adapter` mapping with no `semantic_gap_ids`, contribute no gap;
- if `semantic_gap_ids` exists, it must be a sequence of non-empty strings;
- reject a string scalar in place of a sequence;
- reject duplicate IDs within one event rather than silently deduplicating;
- collect the global sorted unique union.

Malformed adapter metadata must raise:

```text
RuntimeTraceExportSchemaError
```

Do not infer semantic gaps from event type or legacy data.

7. Artifact bytes and digest
----------------------------

Create a frozen dataclass:

```python
RuntimeTraceArtifact:
    document: RuntimeTraceDocument
    pretty: bool
    payload_bytes: bytes
    sha256: str
```

Provide a function equivalent to:

```python
build_runtime_trace_artifact(
    document: RuntimeTraceDocument,
    *,
    pretty: bool,
) -> RuntimeTraceArtifact
```

Requirements:

- `pretty` must be an actual bool;
- compact bytes use existing `canonical_json_bytes(document, pretty=False)`;
- pretty bytes use existing `canonical_json_bytes(document, pretty=True)`;
- SHA-256 is lowercase hexadecimal over the exact `payload_bytes`;
- artifact validates that its digest matches its payload;
- repeated builds are byte-identical;
- compact and pretty hashes may differ;
- do not embed the digest into the trace document.

Reference sample expected hashes:

```text

pretty:
71fa9c77239c30c2aa694a2a8e16f84538b37e3191db4318cf20c09154834d8f
```

The produced sample compact JSON must exactly match
`sample.expected_compact_json` in the supplied JSON reference.

8. Explicit file writing
------------------------

Provide a function equivalent to:

```python
write_runtime_trace_artifact(
    artifact: RuntimeTraceArtifact,
    path: str | pathlib.Path,
    *,
    overwrite: bool,
) -> pathlib.Path
```

Requirements:

- `overwrite` is mandatory and must be an actual bool;
- artifact must be `RuntimeTraceArtifact`;
- target path must name a file, not an existing directory;
- parent directory must already exist;
- do not silently create parent directories;
- `overwrite=False` uses create-new semantics and rejects an existing target;
- `overwrite=True` replaces exactly the requested target;
- write exact `artifact.payload_bytes`;
- return the resolved or normalized `Path` without changing file contents;
- wrap controlled file-system failures as `RuntimeTraceFileError`;
- do not write sidecar hashes or additional files;
- do not write anywhere unless this function is explicitly called.
