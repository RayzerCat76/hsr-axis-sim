1. Explicit loader policies
---------------------------

Define stable string enums:

```text
TraceCanonicalFormPolicy:
  COMPACT_ONLY
  PRETTY_ONLY
  EITHER_CANONICAL

TraceCanonicalForm:
  COMPACT
  PRETTY

TraceDigestPolicy:
  REQUIRE_MATCH
  VERIFY_IF_PROVIDED
  SKIP

TraceDigestStatus:
  MATCHED
  NOT_PROVIDED
  SKIPPED
```

No policy may have a default.

Create a frozen config:

```python
RuntimeTraceLoadConfig:
    canonical_form_policy: TraceCanonicalFormPolicy
    digest_policy: TraceDigestPolicy
    expected_sha256: str | None
    max_bytes: int
```

Validation:

- all fields are mandatory;
- enum values must be exact enum instances;
- `max_bytes` is an integer greater than zero and not bool;
- expected digest, when present, is exactly 64 lowercase hexadecimal chars;
- `REQUIRE_MATCH` requires a digest;
- `VERIFY_IF_PROVIDED` permits null or a valid digest;
- `SKIP` requires null expected digest;
- config is frozen.

3. Load result
--------------

Create a frozen dataclass:

```python
RuntimeTraceLoadResult:
    artifact: RuntimeTraceArtifact
    canonical_form: TraceCanonicalForm
    digest_status: TraceDigestStatus
    expected_sha256: str | None
    source_size_bytes: int
```

Validation:

- artifact is a RuntimeTraceArtifact;
- canonical form agrees with `artifact.pretty`;
- source size equals `len(artifact.payload_bytes)`;
- expected digest format is valid if present;
- MATCHED requires an expected digest equal to artifact SHA-256;
- NOT_PROVIDED requires expected digest null;
- SKIPPED requires expected digest null;
- frozen.

4. Strict JSON decoding
-----------------------

Create a decoder that:

- accepts text already decoded as strict UTF-8;
- rejects duplicate keys at every nesting level with `DuplicateJsonKeyError`;
- rejects NaN, Infinity, and -Infinity;
- requires the root to be a JSON object;
- does not use `object_hook` behavior that loses duplicate-key information;
- does not coerce unknown objects;
- returns ordinary JSON-native data for schema reconstruction.

Input bytes:

- must be exact `bytes`, not arbitrary buffer objects;
- must not exceed `max_bytes`;
- must decode with strict UTF-8;
- UTF-8 BOM is rejected explicitly;
- empty input fails as controlled JSON/encoding input.

6. Independent document-integrity validator
-------------------------------------------

Provide:

```python
validate_runtime_trace_document_v1(
    document: RuntimeTraceDocument,
) -> None
```

It must independently verify:

- exact schema name/version;
- every record's `sequence == record.event.sequence`;
- all event IDs are unique;
- selected sequence policy:
  - CONTIGUOUS: next == previous + 1
  - STRICTLY_INCREASING: next > previous
- record count;
- first/last boundaries;
- exact event-type counts;
- all record contexts are None;
- all numeric mappings are empty;
- all notes are empty;
- semantic-gap IDs equal the exact sorted unique union from validated
  `event.payload.adapter.semantic_gap_ids`.

Semantic-gap rules:

- absent adapter contributes no gaps;
- adapter, if present, must be a mapping;
- absent semantic_gap_ids contributes no gaps;
- semantic_gap_ids must be a JSON array/sequence, not a string scalar;
- every ID is a non-empty string;
- duplicate IDs within one event are rejected;
- no gap is inferred from event type.

Do not silently recompute and replace incorrect summary fields.

7. Bytes loading
----------------

Provide:

```python
load_runtime_trace_bytes(
    payload_bytes: bytes,
    *,
    config: RuntimeTraceLoadConfig,
) -> RuntimeTraceLoadResult
```

Required validation order:

```text
1. config
2. payload type and max size
3. calculate SHA-256 and enforce digest policy
4. UTF-8/BOM
5. JSON duplicate keys/constants
6. exact schema and enums
7. immutable reconstruction
8. document integrity
9. canonical form
```

Digest behavior:

```text
REQUIRE_MATCH:
  mismatch → RuntimeTraceDigestMismatchError
  match → MATCHED

VERIFY_IF_PROVIDED:
  expected null → NOT_PROVIDED
  expected present and match → MATCHED
  mismatch → RuntimeTraceDigestMismatchError

SKIP:
  digest is still calculated for RuntimeTraceArtifact
  digest_status = SKIPPED
```

Canonical behavior:

- reconstruct document;
- generate exact compact and pretty bytes using existing
  `canonical_json_bytes`;
- source bytes must equal one canonical form;
- enforce selected canonical-form policy;
- equivalent noncanonical JSON is rejected;
- artifact payload must remain the exact source bytes;
- do not embed or rewrite hashes.
