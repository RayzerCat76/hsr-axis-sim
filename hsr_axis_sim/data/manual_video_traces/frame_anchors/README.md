# Frame Anchors

Frame anchors are approximate media evidence for an action-sequence-only trace. Their timestamps are seconds from the start of the local media clip; they are not simulator time, action value (AV), speed, delay, or combat values.

Representative frames may be generated by the Video Trace Assistant. The frame files do not need to be committed to the main repository. This metadata layer remains non-executable and must not be used to infer combat state.
